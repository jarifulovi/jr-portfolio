## Portfolio Website

This is a personal portfolio website built with Next.js, React, and Tailwind CSS.

### Features
- Modern, responsive design
- Data-driven sections (Profile, Projects, Skills, Experience, Education)
- Animated UI with Framer Motion
- Modular, reusable components
- JSON-based data for easy updates

### Getting Started
1. Install dependencies:
	```bash
	npm install
	```
2. Start the development server:
	```bash
	npm run dev
	```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Project Structure
- `src/app/` — Main app and page layout
- `src/components/` — UI and section components
- `src/data/` — Portfolio data in JSON files

### Customization
Edit the JSON files in `src/data/` to update your profile, projects, skills, and experience.
